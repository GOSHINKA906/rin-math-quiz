# りんの九九ガーデン

小学2年生向けの掛け算アプリ。うさぎの「もも」と10問の九九で遊びます。

- 2〜5の段／1〜9の段、3択回答
- 回答するたびにお花が咲く進行表示
- 正解、不正解のやさしいフィードバックと結果画面
- 効果音の切り替え、スマートフォン対応、動きを減らす設定への対応
- 数量の絵は「1皿の数 × お皿の枚数」で表示

このフォルダの index.html をブラウザで開くと遊べます。外部ライブラリや通信は不要です。お花とスコアは今回の10問の記録で、再プレイや再読み込みでリセットされます。
