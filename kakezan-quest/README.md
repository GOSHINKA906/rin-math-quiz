# りんの九九ガーデン

小学2年生向けの、10本の花を育てる掛け算ゲームです。`index.html`を開いて遊べます。通信や外部ライブラリは不要です。

- 最初に花の種類と「2〜5の段」「1〜9の段」を選びます。
- 10問には、答えを選ぶ、同じ数ずつジャンプして数える、隠れた数を見つける、の3種類があります。
- 間違えてもその場でやり直せます。ヒントを使って進むこともできます。
- 一問ごとに庭の花が咲き、最後に完成した庭を見られます。
- 効果音は初期状態でオフです。減らす動きの設定にも対応しています。
- 数量モデルは「1鉢の花の数 × 鉢の数」で統一しています。
